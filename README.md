### 🌟 Projeto em destaque

**🏥 Sistema de Agenda, Gestão de Serviço e Digitação de Documentos — Medicina Ocupacional**
*Projeto colaborativo com EXXMED*

Sistema para centralizar o acompanhamento de ordens de serviço técnicas em uma única tela operacional. Construído em **PHP puro** com arquitetura **MVC enxuta**, **SQLite via PDO** e migrations automáticas para criação de tabelas, índices, triggers de auditoria e dados de demonstração.

- 🔍 Filtros combináveis por status, técnico, CNPJ, razão social, tipo de serviço, código de OS e intervalo de datas, além de filtros rápidos (ativos, todos, concluídos)
- ⚡ Menu de contexto e ações em massa para atualização de status/técnico
- 📋 Painel lateral (slide-over) com detalhes da OS e histórico de auditoria
- 🔐 Dois perfis de acesso (técnico e comercial, este último somente leitura)
- 🎨 Front-end com jQuery, DataTables, SweetAlert2, Bootstrap 5.3 e Tailwind CSS
